# 🌱 CarbonWise AI

An AI-powered carbon footprint tracking platform that helps users measure, analyze, and reduce their environmental impact. The application provides personalized sustainability insights, emissions analytics, and actionable recommendations through an intuitive dashboard.

---

## 🚀 Features

- 🌍 Calculate personal carbon footprint
- 📊 Interactive emissions analytics dashboard
- 🎯 Sustainability score and impact meter
- 💡 AI-powered eco-friendly recommendations
- 📈 Progress tracking toward emission reduction goals
- ♻️ Personalized lifestyle improvement suggestions
- 📱 Modern, responsive user interface

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** shadcn/ui
- **API:** Next.js Route Handlers
- **Deployment:** Vercel

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/PR0801/CarbonWise-AI.git
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```
